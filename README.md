# 🎬 Netflix Titles Analysis

## 📌 Project Overview

**Netflix Titles Analysis** is a Python-based exploratory data analysis project focused on analyzing Netflix's movies and TV shows catalog.

The project uses **Python, Pandas, NumPy, Matplotlib, and Seaborn** to clean, transform, analyze, and visualize Netflix content data.

The analysis explores Netflix's content distribution, release trends, countries, genres, ratings, directors, actors, movie duration, content additions over time, and international diversity.

The objective is to transform raw Netflix title data into meaningful insights that can help understand **content strategy, audience targeting, global expansion, and catalog trends**.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze Netflix's Movies vs TV Shows distribution
* Understand Netflix's content growth over time
* Identify countries producing the most Netflix content
* Analyze the most common content ratings
* Identify the most popular genres
* Analyze movie and TV show trends
* Study Netflix content additions by year and month
* Identify the most frequent directors and actors
* Analyze movie duration
* Understand TV Show genre distribution
* Analyze international content diversity
* Identify patterns that can provide business and audience insights

---

## 📊 Dataset

The project uses the **Netflix Titles Dataset** containing information about Netflix movies and TV shows.

The dataset contains **5,398 records and 12 columns** in the notebook.

### Dataset Features

| Column         | Description                                    |
| -------------- | ---------------------------------------------- |
| `show_id`      | Unique identifier for each Netflix title       |
| `type`         | Content type: Movie or TV Show                 |
| `title`        | Name of the movie or TV show                   |
| `director`     | Director of the title                          |
| `cast`         | Actors and performers                          |
| `country`      | Country or countries associated with the title |
| `date_added`   | Date when the title was added to Netflix       |
| `release_year` | Original release year                          |
| `rating`       | Audience/content rating                        |
| `duration`     | Movie duration or number of TV show seasons    |
| `listed_in`    | Genres/categories associated with the title    |
| `description`  | Description of the title                       |

# 📈 Key Business Insights

Based on the analysis, the project identifies several important insights:

### 🎬 Content Strategy

* Movies make up the majority of Netflix's catalog.
* TV Shows have grown steadily in recent years.
* Netflix maintains both modern and older content.

### 🌎 Global Expansion

* The United States is a major contributor to Netflix's catalog.
* Netflix contains content from many countries.
* International content has become increasingly important.
* The catalog demonstrates growing global diversity.

### 🎭 Genre Strategy

* International Movies are highly represented.
* Drama and Comedy are major movie categories.
* International TV Shows and TV Dramas are prominent TV categories.
* Crime-related TV content is also strongly represented.

### 👥 Audience Strategy

* TV-MA and TV-14 are dominant ratings.
* Netflix has a significant focus on mature and teenage audiences.
* The platform combines mainstream entertainment with international and culturally diverse content.

### 🎥 Content Creators

* Certain directors appear repeatedly across the catalog.
* Several actors have frequent appearances.
* Recurring creators and performers may indicate established industry relationships.
